本题讲解：2024 完形第 19 空 · “你____社交的那段时间”填哪个形容词

答案：B（unavailable 没空的；不能/不愿的）。

第 0 步：先立机制——定语从句里的 be + adj. + for 结构

some time in your diary when you’re ____ for socialising 是修饰 some time 的定语从句；四个选项均为形容词，构成 be + adj. + for sth 的系表结构。这段 some time 的下文是 use this time to relax... and recover——它是被特意腾出来“不社交、只休息”的时间。所以空格形容词要表达“没空／不愿社交”，而不是任何带评价色彩的情绪词。

第 1 步：定位原文

Make sure you __18__ some time in your diary when you’re __19__ for socialising and use this time to relax, __20__ and recover.

第 2 步：找证据——这段时间的用途反推形容词

...and use this time to relax, __20__ and recover.

对策的目的是避免社交疲劳（上文 social burnout）：把一段时间标出来专门休息，等于宣布这段时间“谢绝社交”。be ____ for socialising 因此应取“没空、不便、不去”之义。

第 3 步：逐项排除

选项词义判定理由
A ungrateful不领情的✗含贬义、带指责色彩；全文是客观建议口吻，情感色彩不符
B unavailable没空的✓be unavailable for sth = 没空做某事；“标出你没空社交的时间来休息”贴合对策逻辑
C responsible负责的✗be responsible for sth 是“对某事负责”；socialising 是个人意愿的选择，谈不上“负责”
D regretful后悔的✗“后悔社交”的前提是已经社交过，与“把这段时间用来放松”衔接不上

第 4 步：预判追问

  • 为什么 D 迷惑性大？：命题人利用上文“社交过度的种种危害”诱导出“后悔社交”。但 be regretful for 的语义重心是“对已发生的事感到懊悔”，本句的 some time 是前瞻性安排（腾出来的休息时间），不存在懊悔对象。
  • unavailable 不是“不可获得的”吗？：形容人时取“没空、不便出面”之义，如 The manager is unavailable today。be unavailable for socialising 即“没空社交”。

易错点

  • 误选 D（regretful）：顺着“社交过度有危害”脑补“会后悔”，没检查 regretful 的语义前提与从句用途是否兼容。
  • 误选 C（responsible）：只认得 be responsible for 这一高频搭配，不问“对社交负责”在文中是否成立。
记忆锚点：腾出来休息的时间 = when you’re unavailable for socialising；responsible for 管“责任”，regretful for 管“懊悔”，都要有成立前提。
