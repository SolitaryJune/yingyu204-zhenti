答案

答案：D

16

本题讲解：2013 完形第 16 空 · often 泄露的天机——not uncommon

答案：D（uncommon 不常见的）。

第 0 步：先立机制——双重否定里藏着频度判断

空格被三层包裹：not（否定）+ an ___ occurrence（一个 ___ 的事件）。this 回指上一句“黑客潜入数据库篡改信息”整件事。occurrence（事件、发生的事）被形容词评价的常见维度是“频率”——事件常不常见。句意再往下推：The fact… means that dishonest persons might…（这件事不稀奇，意味着坏人可能得手）——只有“常见”才能推出“风险真实存在”。所以空格填“不常见”，与 not 叠成双重否定：并非罕见 = 时有发生。

第 1 步：定位原文

The fact that this is not an __16__ occurrence means that dishonest persons might be able to access bank accounts in electronic payments systems and __17__ from someone else’s accounts.

not an ___ occurrence：否定 + 元音开头的形容词 + occurrence。unsafe / unnatural / unclear / uncommon 四个 un- 家族词，靠频度线索定 uncommon。

第 2 步：找证据——频度探针：上一句句首的 often

We often hear media reports that an unauthorized hacker has been able to access a computer database and to alter information stored there.

often（经常听到媒体报道）直接给出频度证据：这类事件不稀奇。not uncommon 是英语里委婉而语气更强的“很常见”；后文“坏人可能得手”的推断也只有在“常见”的前提下才成立。

第 3 步：逐项排除

选项词义判定理由与典型误解
A unsafe不安全的✗ 排除occurrence（事件）本身无所谓安全不安全，评价维度错位；not an unsafe occurrence 也推不出后文。（典型误解：被全段 security 话题裹挟。）
B unnatural不自然的✗ 排除occurrence 没有“自然/不自然”属性，often 的铺垫用不上。（典型误解：un- 词族里随手抓一个。）
C unclear不清晰的✗ 排除unclear 修饰信息、表述，修饰“事件的发生频率”不通。（典型误解：词形相近的盲选。）
D uncommon不常见的✓ 当选not an uncommon occurrence = 双重否定 → 相当常见：often 的铺垫与后文“坏人可能得手”全部接通。（易错警示：unsafe 与 security 最近，但本空评的是频率；often 是探针。）

代入后的完整句义：这类事件并非罕见（= 时有发生），这意味着不诚实的人有可能进入电子支付系统的银行账户，从他人账户中窃取资金。

第 4 步：预判追问

  • not uncommon 为什么算“常见”？：not + uncommon（不常见）双重否定 = “不在“不常见”之列”，即常见；英语惯用 not uncommon / not unusual 做委婉但更强调的说法。
  • this 指什么？：the fact that this is… 中 this 回指上一句整件事：黑客访问计算机数据库并篡改其中储存的信息。

易错点

  • 误选 A（unsafe）：被全段 security 话题裹挟。
  • 误选 B（unnatural）：un- 词族里随手抓一个。
  • 误选 C（unclear）：词形相近的盲选。
记忆锚点：not an uncommon occurrence = 并不罕见 = 时有发生；频度词 often 是“频率空”的探针；双否定 = 委婉的强调。
