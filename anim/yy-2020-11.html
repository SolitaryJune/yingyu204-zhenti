本题讲解：2020 完形第 11 空 · 悔意 + start over 同向——习语 turn back the clock

答案：A（turn back 往回走；翻回到）。

第 0 步：先立机制——and 并列定方向，具象 clock 指抽象 time

选词分两步。第一步定方向：上文刚说完"发怒、说狠话、对谁都没好处"——懊悔；本句 You wish（你多希望）+ and start over（从头再来）——"重来"的语义方向就是"回到过去"，and 并列约束空格短语与 start over 同向。第二步核搭配：the clock 在这里是"时间"的具象化身，动词必须能借"钟"表达"时光倒流"的抽象义——习语 turn back the clock（使时光倒流）正中靶心。其余三个短语的宾语若真是"一台钟"倒还成立，但"拆钟/搁钟/盖钟"都传不出"回到过去"。

第 1 步：定位原文

You wish that you could __11__ the clock and start over.

空格动词短语接 the clock，与 start over（从头再来）由 and 并列：语义必须同向。

第 2 步：找证据——懊悔语境与 start over 的方向

  • 语境：发怒说狠话、对谁都没好处 → 懊悔（You wish）；
  • 并列：____ the clock and start over——同向：回到过去；
  • 指代：the clock 借具象"钟表"指抽象"时间"；
  • 习语：turn back the clock = 使时光倒流。

第 3 步：逐项排除

选项词义判定理由与典型误解
A turn back往回走；翻回到✓ 当选turn back the clock = 使时光倒流：与 start over 同向（回到过去），习语成立。
B take apart拆开；剖析✗ 排除"把钟拆开"只停留在物理操作，传达不出"回到过去"的抽象义。（典型误解：就词面理解 the clock，不识具象指抽象。）
C set aside留出；驳回；不顾✗ 排除"把钟搁在一边"指向"不顾时间（流逝）"，与"悔过重来"无关。
D cover up掩盖，盖住✗ 排除"把钟盖住"指向"掩盖时间（流逝）"，同样接不上"从头再来"。

代入后的完整句义：你多希望自己能让时光倒流、从头再来。

第 4 步：预判追问

  • take apart the clock 当作字面义"拆钟"不就通了吗？：字面上通，文意上不通：文中的 clock 是"时间"的化身，句子要表达的是"回到过去"；"拆钟"与懊悔、重来毫无关联——选词必须落在抽象义上。

易错点

  • 误选 B（take apart）：就词面选词，把"时光倒流"的习语误读成物理操作。
记忆锚点：turn back the clock 使时光倒流；and 并列 → 与 start over 同向；具象 clock 指代抽象 time。
