本题讲解：2025 完形第 5 空 · 词义辨析 · which 非限从句的表语（感受形容词）

答案：D（uncomfortable 令人担忧的，令人不安的）。

第 0 步：先立机制——which 指整件事，空格给这件事「定性感受」

空格在 which 引导的非限定性定语从句里作表语：which 回指主句整件事（你公开自己的弱点），can be ____ =「这件事可能是____的」。要填的是这件事给人的感受。下文随即铺开担忧清单：怕失去掌控、被接手抢功、惹人厌烦添麻烦——公开弱点的滋味是令人不安。

第 1 步：定位原文，抽证据

You're broadcasting your own weakness, which can be __5__. You might have __6__ about losing control of whatever it is you are asking for help with.

④~⑥句列出了多种具体担忧（怕失去掌控被接手抢功、怕惹人厌烦添麻烦）。这些 worry 都由「公开弱点」引出——作者先把③句定性为「令人不安」，再用④~⑥句举证。所以空格装的感受必须能统领「worry 满篇」的下文。

第 2 步：对号入座：四个选项逐个上桌

选项词义判定理由
A unrealistic不切实际的✗ 排除公开弱点是真实会发生的事（下文全是真实担忧），不存在「不切实际」的问题；它也统领不了 worry 清单。
B deceptive欺骗性的；误导的✗ 排除全文无「欺骗/误导」语境：公开弱点恰恰是把真实情况亮出来。
C tiresome令人厌烦的；讨厌的✗ 排除tiresome 形容任务/过程繁琐惹人烦；这里的情绪是难堪、不安（为下文 worry 铺垫），不是「烦」。
D uncomfortable令人担忧的，令人不安的✓ 当选公开自己的弱点令人不安——正是下文一连串 worry 的总纲，语义与上下文衔接全部咬合。

易错点：每个干扰项对应哪种误解

  • 把「求助难」误读成「这种想法不现实」 → 误选 A（unrealistic）：公开弱点是真实会发生的事（下文全是真实担忧），不存在「不切实际」的问题；它也统领不了 worry 清单。
  • 把 weakness 与「说谎」错误挂钩 → 误选 B（deceptive）：全文无「欺骗/误导」语境：公开弱点恰恰是把真实情况亮出来。
  • 把「不安」与「厌烦」两种情绪混为一谈 → 误选 C（tiresome）：tiresome 形容任务/过程繁琐惹人烦；这里的情绪是难堪、不安（为下文 worry 铺垫），不是「烦」。
记忆锚点：which can be ____ 先锁定 which = 主句整件事，再让下文的担忧清单投票：满篇 worry → uncomfortable；tiresome 是「烦」，不是「怕」。
