本题讲解：2024 完形第 20 空 · “放松、____、恢复”并列的动词

答案：D（rest 休息）。

第 0 步：先立机制——并列结构锁定语义场

to relax, __20__ and recover 是 and 连接的三个并列不定式，作 use this time 的目的状语。并列结构是完形的高价值线索：三个词共享同一个语义场。relax（放松）、recover（恢复精力）已定，中间缺的一环必然是“休息”义动词——这就是本空的全部机制，先定语义场，再辨词。

第 1 步：定位原文

...and use this time to relax, __20__ and recover.

第 2 步：语义推演

被标出的时间是“没空社交”的专属时间（见第 19 空），用途链条是：放松身心 → 停下来歇息 → 恢复精力。D rest 与前后两词构成 relax → rest → recover 的同场递进，完整实现“腾出时间”的意图。

第 3 步：逐项排除

选项词义判定理由
A react反应✗react 暗含“对某事作出反应”，须接 to 引出对象；此处单独使用表意不明，也无法与 relax/recover 并列
B repeat重复✗“放松后再来一轮”是脑补的循环义，repeat 自身表达不出，且不属“休息”语义场
C return返回；恢复✗中文释义“恢复”与 recover 近义是设障点：return 取“恢复”义时主语是感觉/情形（Her appetite had returned），本空逻辑主语是 you
D rest休息✓与 relax、recover 近义并列，“放松、休息、恢复”层层递进，契合腾出时间的目的

第 4 步：预判追问

  • return 不是也有“恢复”的意思吗？：return 表“恢复”指感觉、情形回到原状或再度出现，主语是物：Her appetite had returned（她胃口又好了）。本空不定式的逻辑主语是 you——“你恢复”该用 recover，return 进不了这个句位。
  • react 在语法上为何别扭？：react 是不及物动词，反应必有对象（react to sth）；并列结构里前后都是裸动词 relax、recover，夹一个必须带 to 的词，结构失衡。

易错点

  • 误选 C（return）：只对中文释义“恢复=恢复”做匹配，没查英文搭配的主语限制。
  • 误选 B（repeat）：把“循环休息”的合理想象当成词义本身，忽视并列结构要求语义同场。
记忆锚点：并列不定式共享语义场——relax / rest / recover；return 的“恢复”主语是物，react 必带 to，repeat 表不了循环。
