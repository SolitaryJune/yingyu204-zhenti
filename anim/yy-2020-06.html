本题讲解：2020 完形第 6 空 · this 回指 to be patient——表语要和主语同类呼应

答案：B（task 任务；工作）。

第 0 步：先立机制——先解决 this 的回指，再让表语与它"同类呼应"

主语 this 回指上文的不定式 to be patient——"变得有耐心"是一个目标。表语 no easy ____ 必须能和"目标"同类呼应："成为一个有耐心的人，不是一件容易的____"——填"任务/事"才通：no easy task（非易事）正是惯用表达。排除时抓两头：一是语义同类（task/事）；二是结构搭配——access 这类名词有自己的固定句型（no easy access to sth），套不进 sth is no easy ____ 的骨架。

第 1 步：定位原文

Still, while every parent would like to be patient, this is no easy __6__ .

空格做表语：this（主语）is no easy ____。this 指什么，决定了表语选什么。

第 2 步：找证据——this 的回指对象与搭配结构

  • 回指：this = to be patient（变得有耐心）——性质是"目标"；
  • 呼应：目标 ↔ 任务（task）：no easy task = 非易事，惯用；
  • 结构核验：access 惯用 no easy access to sth，没有 sth is no easy access 的说法；answer/choice 语义接不上"目标"。

第 3 步：逐项排除

选项词义判定理由与典型误解
A answer答案，解决办法✗ 排除"耐心是个答案"不通；若理解成"耐心未必解决问题"，又与上一句"孩子各年龄段都受益于耐心"矛盾。
B task任务；工作✓ 当选与主语 this（目标）同类呼应："变得有耐心"是项任务、并非易事；no easy task 为惯用搭配。
C choice选择；被选中的东西✗ 排除文意是"耐心本身难达成"，不是"做出选择很难"——把"难达成"偷换成"难选择"。（典型误解：没分清"达成难"与"选择难"。）
D access通路；机会，权利✗ 排除双重排除：结构上没有 sth is no easy access 的说法（惯用是 (there is) no easy access to sth）；语义上 access 的对象是资源、设施、场所、人，"变耐心"是目标，配不上。（典型误解：只看中文释义"能获得"，不核句型骨架与搭配对象。）

代入后的完整句义：不过，尽管每位父母都想做到有耐心，这却不是一件容易的事（并非易事）。

第 4 步：预判追问

  • access 为什么连语法都不合格？：access 表"获得/使用（某物）的机会或权利"，必须指向"被获取的对象"：惯用 no easy access to sth。本句骨架是 this is no easy ____，没有 to sth 的位置；且"变得有耐心"不是可 access 的资源或场所。

易错点

  • 误选 C（choice）：把"耐心难达成"偷换成"选择难做"。
记忆锚点：this 回指 → 表语同类呼应；no easy task 非易事；access 必带 to sth 且对象是资源。
