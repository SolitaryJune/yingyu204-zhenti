本题讲解：2013 完形第 6 空 · 几个因素在“拖后腿”——work against

答案：B（against 对抗；妨碍）。

第 0 步：先立机制——总起句方向由 First/Second/Third 决定

本句是第二段总起句：Although 让步从句先把对方最强的理由摆出来（电子支付更高效），主句给出转折——“即便如此，纸币系统照样没有消失”，并交代原因是 several factors。空格是 work ___ the disappearance 的介词位：选定的介词决定这些因素对“纸币系统消失”是推还是挡。方向不能凭感觉，要往下读 First / Second / Third 三条论据再回头定。

第 1 步：定位原文

Although electronic means of payment may be more efficient than a payments system based on paper, several factors work __6__ the disappearance of the paper system.

work for / work against / work with / work on 四个短语介词义各不相同；本题考的正是 work 与介词的搭配义，以及与段落论据的对齐。

第 2 步：找证据——三条论据全是“帮纸币续命”

First, it is very expensive to set up the computer, card reader, and telecommunications networks… / Second, paper checks have the advantage that they provide receipts… / Third, the use of paper checks gives consumers several days of "float"…

代价高昂（建不起来）、收据凭证（消费者不肯放）、浮动期利息（消费者不肯换）——三条理由全部在为纸币系统的“不消失”辩护。所以 factors 是在对抗 disappearance：work against。

第 3 步：逐项排除

选项词义判定理由与典型误解
A for受雇于；有利于✗ 排除work for the disappearance 会被读成“这些因素有利于纸币系统消失”，与 First / Second / Third 三条论据全部反向。（典型误解：只背 work for = 有利于，没有核对本段论据方向。）
B against对抗；妨碍✓ 当选work against the disappearance = 阻碍纸币系统的消失，正好统摄三条“帮纸币续命”的论据。（易错警示：work for 字面更眼熟，但介词方向必须服从 First / Second / Third 的论据。）
C with与……共事；协作✗ 排除factors（因素）与 disappearance（消失）之间无“协作”可言，搭配对象错位。（典型误解：见 work 就想 with。）
D on从事于；致力于✗ 排除work on 的主语一般是人（致力于某项工作），factors 不是施动者。（典型误解：把 factors 拟人化。）

代入后的完整句义：尽管电子支付手段可能比纸币支付系统更高效，但若干因素在阻碍纸币支付系统的消失。

第 4 步：预判追问

  • Although 从句不是在说电子支付“更高效”吗，为什么主句反而护着纸币？：让步从句的作用是先把对方最强的理由摆上台面（承认高效），主句再顶回去（即便如此也没消失）——这正是“列原因”的标准写法：原因越硬，主句的反差越成立。
  • work against 还有哪些高频语境？：work against sb/sth = 对……不利、起反作用，如 The clock is working against us（时间对我们不利）。反义方向是 work for / toward。

易错点

  • 误选 A（for）：只背 work for = 有利于，没有核对本段论据方向。
  • 误选 C（with）：见 work 就想 with。
  • 误选 D（on）：把 factors 拟人化。
记忆锚点：work against = 阻碍、起反作用；总起句的方向由 First/Second/Third 决定——先读论据，再定介词。
