本题讲解：脆弱性地图的两个用途合并成一句话

答案：B（target areas needing special attention 确定需要特别关注的区域）。

第 0 步：先立机制——这道题的定位对象是"一个工具"

题目问的不是 HAPs 整体、也不是某次事件，而是 vulnerability map（脆弱性地图）这个具体工具能帮什么忙。细节题锁定工具，就要把原文里这个工具的每一次出场都找齐——只看一处容易以偏概全。vulnerability map 原词出现在段 4②句和段 5④句，Kotharkar 即段 4②句的 she。

第 1 步：定位原文（两处合并）

段 4②：all cities should create a vulnerability map to help focus responses on the populations most at risk.

>

段 5④：The Nagpur project has already created a risk and vulnerability map, which enabled Kotharkar to tell officials which neighborhoods to focus on in the event of a heat wave this summer.

段 4②给理论用途：把应对聚焦到风险最高的人群；段 5④给现实实例：地图让 Kotharkar 能告诉官员该重点关注哪些街区。两处说的是同一件事的两个侧面。

第 2 步：同义替换定 B

"聚焦风险最高的人群" + "指出该关注的街区" = target areas needing special attention（确定需要特别关注的区域）。target 对应 focus on，areas 对应 populations / neighborhoods。

第 3 步：逐项排除

选项判定干扰项归因
A prevent the harm of high humidity✗ 无中生有humidity 出现在段 2⑤、段 3③，是"衡量风险的指标/加重因素"，与地图功能毫无关系——拿全篇出现过的词给选项当靠山
C expand the Nagpur project's coverage✗ 曲解文意地图帮官员锁定该关注的街区，是聚焦不是扩大覆盖——方向恰好相反
D make relief plans for heat-stricken people✗ 过度推理"清凉病房救治中暑患者"是 HAPs 的内容，与地图无关；"聚焦风险人群"（识别）推不出"制定救助计划"（执行）

预判追问

  • 为什么要看两处？ 段 4②只说"应该建"，段 5④才展示"建了以后具体怎么用"。单看任一句都可能概括偏；两处合并才能得到"锁定高危区域"这一准确功能。
  • D 错在哪一步？ 识别（identify）与执行（make plans）是两个环节。地图只负责前者。
记忆锚点：vulnerability map ⇒ focus on…most at risk / which neighborhoods to focus on ⇒ 锁定高危人群与街区；A 词面沾边、C 方向相反、D 多走一步。
