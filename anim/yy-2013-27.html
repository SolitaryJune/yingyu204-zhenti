本题讲解：2013 阅读第 27 题 · 第二段暗示：美国现行移民制度如何

答案：C（should be adapted to meet challenges 应当调整以迎接挑战）。

第 0 步：先立机制——implied 题的方向校验

题干 It is implied（暗示）≠ 原词照搬：正确项是对作者“态度 + 呼吁”的概括，干扰项则在方向上做手脚。方向反转有三种常见形态——肯定 / 否定反转、反义词替换、未完成 / 已完成反转。解法：先圈出段落里的态度词定基调，再逐项核对方向。

第 1 步：圈态度词——三个全负

Today, we are much more rigid about immigrants... That framework has contributed mightily to our broken immigration system and the long political paralysis over how to fix it.

态度词三个全负：rigid（对移民更加严苛）、broken（千疮百孔的）、paralysis（瘫痪）。现行制度 = 把移民分成“合法 / 非法、好 / 坏”两类，结果制度失灵、政治僵局——作者在批评它。

第 2 步：找呼吁

We don't need more categories, but we need to change the way we think about categories... We might then begin to solve our immigration challenges.

作者的呼吁：不是增加新类别，而是改变对类别的思维方式、超越“合法 / 非法”的严格定义、承认灰色地带——这样才能“开始解决移民挑战”。批评 + 呼吁 ⇒ 现行制度应当调整以应对挑战。

第 3 步：逐项排除

选项判定理由与典型误解
A needs new immigrant categories✗ 排除否定反转：原文白纸黑字 We don't need more categories——不需要更多类别，需要的是改变“看待类别的方式”。（典型误解：只看到 category 是话题词，没看到 don't。）
B has loosened control over immigrants✗ 排除反义替换：原文 much more rigid（更加严苛）⇒ 收紧，[B] 说“放松”——方向完全相反。（典型误解：rigid 词义不熟，凭印象反着选。）
C should be adapted to meet challenges✓ 当选三源合成：rigid / broken / paralysis（该改）+ change the way we think（怎么改）+ solve our immigration challenges（为什么改）。
D has been fixed via political means✗ 排除未完成 / 已完成反转：the long political paralysis over how to fix it 说的是“如何修复”久拖不决——还没修好，[D] 却说“已经通过政治手段修好”。（典型误解：不认识 paralysis，被 political means 带偏。）

第 4 步：预判追问

  • paralysis 不认识怎么办？：看并列成分——它与 broken immigration system 由 and 并列，同为 that framework 的后果；broken 已定负面基调，paralysis 必然同向（瘫痪、僵局）。猜词线索就在句内。
  • 正确项 C 为什么不是“原词”？：implied 题的正确项本来就不是原词，而是把“批评（该改）+ 呼吁（怎么改）+ 目的（为什么改）”三点合成的概括。原词重现的 A、B、D 反而各带一处方向反转——这是 implied 题的典型出题手筋。

易错点

  • 误选 A：漏看 don't，把“不要更多类别”读成“需要新类别”。
  • 误选 D：被 political means 吸引，没核对“修复”这件事在文中的状态（未完成）。
记忆锚点：implied 题 = 态度词定方向：rigid / broken / paralysis 三连负面 ⇒ “制度该改”；否定词 don't（A）、反义词 rigid / loosened（B）、未修 vs 已修（D）——三种方向反转各有归属。
