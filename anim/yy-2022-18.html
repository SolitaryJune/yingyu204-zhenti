本题讲解：完形第 18 题——the + 比较级句型与"光阴飞逝"的上下文语义

答案：D（quicker）。

第一步：先立机制——先看句型空槽，再向上下文要词义

"The older you get, the __18__ it seems to go" 是 the + 比较级，the + 比较级句型："越……就越……"。空格填比较级副词修饰 go，主语 it 回指上句的 time——整句谈的是时间流逝。词性由句型锁定，词义方向则由上下文给出。

第二步：定位原文——末段的三句链条

Time is finite.
We need to use it as carefully and as __19__ as we can, that means prioritising our activities so that we spend most time on the things we really want to do.
  • ①句 Time is finite（时间是有限的）：给末段定调；
  • ②句（空格句）：年龄越大，时间似乎流逝得越____；
  • ③句顺承提出建议：要尽可能谨慎、有效地利用时间。

①③两句夹住②句：时间有限 → 所以催人抓紧，中间只能填"流逝得快"。推导链：finite（有限）+ 建议善用 → 光阴飞逝 → quicker。

第三步：逐项排除（对号入座）

  • A duller ✗："时间流逝得乏味"在文中无来源——末段谈的是时间的紧迫，不是乏味。
  • B harder ✗：把"年纪大了日子更难"的生活常识代入空格；原文的叙事焦点是时间有限要抓紧，不是年老的艰难。
  • C quieter ✗："流逝得更安静"与 go 的搭配牵强，也和末段主旨无关。
  • D quicker ✓：与 finite 呼应、与③句"抓紧利用"的建议顺接——时间有限且飞逝，所以要排定优先次序。

易错点

  • 误选 B（最强干扰）：harder 能体现"年老"的特点，属于"选项符合常识但不符合上下文主旨"的典型干扰；完形语义题以上下文逻辑为准，不以常识感受为准。
  • 误选 A/C：三项干扰都停留在"年老的生活特点"这一表面层面，而②句真正要的是对"时间流逝"的描述。
记忆锚点：the + 比较级句型先定词性（比较级副词）；"时间有限 + 催人善用" → 光阴飞逝 = the quicker it seems to go。
