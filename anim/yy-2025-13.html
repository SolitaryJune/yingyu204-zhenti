本题讲解：2025 完形第 13 空 · 词义辨析 · To ____ these difficulties（目的状语）

答案：D（overcome 克服；解决）。

第 0 步：先立机制——these difficulties 指什么，决定动词往哪走

空格在 To ____ these difficulties 的不定式里作目的状语：为了____这些困难，后文给出做法（提醒自己人人需要帮助）。these difficulties 承上指代①②句的种种困难——怕被拒、怕负面暗示。对「已经摆上桌的困难」+ 引出「对策」的，是 overcome（克服）。

第 1 步：定位原文，抽证据

To __13__ these difficulties, try to remind yourself that everyone needs help sometimes.

④⑤句（没有人无所不知；研究显示求助者反而被视为更有能力）与第④段的研究，都在给求助者打气——是典型的「帮你克服心理困难」的论据。目的状语 To ____ these difficulties 之后，跟的自然是解药而不是分析。

第 2 步：对号入座：四个选项逐个上桌

选项词义判定理由
A explain解释，说明✗ 排除「为了解释这些困难」方向反了：后文给的是对策与鼓励，不是成因分析。
B identify认出；找到✗ 排除困难在上文已经逐条列明（怕被拒、怕负面暗示），无须再「识别」；identify 也不引出「提醒自己」式的打气。
C predict预言；预告✗ 排除困难是当事人正在经历的，不是未来事件；「预测困难」与后文对策不接。
D overcome克服；解决✓ 当选overcome difficulties 是标准搭配；「为了克服这些困难，试着提醒自己……」——目的与手段严丝合缝。

易错点：每个干扰项对应哪种误解

  • 把「讲解困难」当成引出建议的合理铺垫 → 误选 A（explain）：「为了解释这些困难」方向反了：后文给的是对策与鼓励，不是成因分析。
  • 把「意识到问题」误当成解决问题的第一步 → 误选 B（identify）：困难在上文已经逐条列明（怕被拒、怕负面暗示），无须再「识别」；identify 也不引出「提醒自己」式的打气。
  • 看到 difficulties 就联想未来风险 → 误选 C（predict）：困难是当事人正在经历的，不是未来事件；「预测困难」与后文对策不接。
记忆锚点：To ____ these difficulties：目的状语要引出「解药」——overcome difficulties（克服困难）；explain 是「分析成因」，identify/predict 都接不上「提醒自己」式的对策。
