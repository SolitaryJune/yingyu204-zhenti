## 本题讲解：2013 阅读第 22 题 · 成为成功的员工必须做什么

答案：**D（contribute something unique 贡献独特的东西）**。

### 第 0 步：先立机制——细节题先抓段内“结论信号词”

题干 According to Paragraph 3 + one has to（必须）→ 范围锁定第三段，问的是“必要条件”。段落结构决定了答案位置：①-④句铺垫“平庸时代结束”，⑤句用 **Therefore** 收束出结论。段落内的因果收束句就是本题的答案句——这是细节题最省力也最可靠的定位方式。

### 第 1 步：定位原文

> But, today, average is officially over... Therefore, everyone needs to find their extra – their unique value contribution that makes them stand out in whatever is their field of employment.

第三段铺垫：过去“平庸”能换来普通生活，如今 But 转折——平庸时代正式结束（average is officially over）；⑤句 Therefore 收束：人人都要找到自己的 extra——让自己在岗位上脱颖而出的**独特价值贡献**。题干 one has to ↔ 原文 needs to，对位精准。

### 第 2 步：同义改写核对

find their extra = their **unique value contribution** → 选项 **contribute something unique**（贡献独特的东西）。逐词能对上：unique → unique，value contribution → contribute something。正确项是答案句的同义改写。

### 第 3 步：逐项排除

| 选项 | 判定 | 理由与典型误解 |
|---|---|---|
| A work on cheap software | ✗ 排除 | 借第④句 cheap software 设障。原文说雇主能轻易获得“廉价软件、廉价自动化”来**替代人工**——这是雇主手里的生产工具，不是对雇员的要求。（典型误解：见选项词在段落里出现过就选，不核对说的是谁的事。） |
| B ask for a moderate salary | ✗ 排除 | 原文没有“要求适中薪水”的建议；moderate（适中）也是对 average 的偷换——原文的 average 指“平庸的水平”。（典型误解：把 average 的“平庸”义错位嫁接到“薪水适中”。） |
| C adopt an average lifestyle | ✗ 排除 | 反向干扰：原文恰恰说 average is officially over——平庸生活方式已经过时，正是要摆脱的东西。（典型误解：没注意到 But 转折后的态度翻转。） |
| D contribute something unique | ✓ 当选 | 答案句 Therefore... unique value contribution 的同义改写。 |

### 第 4 步：预判追问

- **为什么 A 不能算“必要条件”？cheap software 不也是成功要素吗？**：第④句的逻辑是“雇主有更多渠道获取廉价软件等替代品，所以平庸不再有回报”——cheap software 是**逼出结论的背景因素**，不是 Therefore 句里对雇员的要求。答案必须落在结论句上。
- **B 的 moderate 与 C 的 average 有什么区别？**：都属“原词设障”——B 把 average 的“平庸”错位成“适中薪水”，C 则干脆反着来：原文说平庸生活过时了，它让你去采取它。

### 易错点

- **误选 A**：被段落里的原词吸引，不看这句话属于铺垫还是结论。
- **误选 C**：漏看 But 转折，方向正好选反。

> 记忆锚点：细节题先抓段内结论信号词（Therefore）；正确项是 unique value contribution 的同义改写；选项里的“原词”（cheap / average / lifestyle）多半是设障。
