## 本题讲解：2013 完形第 15 空 · 数据库里的信息是“存”着的——stored

答案：**C（stored 储存的）**。

### 第 0 步：先立机制——分词后置定语：先问存放关系

空格在 alter information ___ there 里：information 之后、there 之前，过去分词作后置定语，说明“信息与数据库之间是什么存放关系”。there 回指前半句的 a computer database。数据库之于信息，天然关系就是“存放”——黑客能“改动那里的信息”，前提正是信息被存放在那里。

### 第 1 步：定位原文

> We often hear media reports that an unauthorized hacker has been able to access a computer database and to alter information `__15__` there.

information ___ there：分词定语位。analyzed / shared / stored / displayed 都是真实动作，判定标准是哪一项描述“信息与库的基本关系”而非一次性加工动作。

### 第 2 步：找证据——access a database and alter information there：能改的前提是存着

访问数据库、改动其中的信息——改的对象必然是“库中存放的数据”。be stored in a database 是数据库英语的标准搭配；analyze / display 是对信息的加工与呈现动作，shared 描述的是人与人之间的分发关系，都不是“信息待在库里”的存放状态。

### 第 3 步：逐项排除

| 选项 | 词义 | 判定 | 理由与典型误解 |
|---|---|---|---|
| A analyzed | 分析的 | ✗ 排除 | 分析是对信息的加工动作，不是信息在库中的存放状态。（典型误解：见 database 就联想数据分析。） |
| B shared | 共享的 | ✗ 排除 | “共享”描述人与人之间的分发，不是信息与数据库的存放关系，且与“非授权入侵”叙事冲突。（典型误解：把“联网”直接等同于“共享”。） |
| C stored | 储存的 | ✓ 当选 | information stored there = 存放在那里的信息——信息被储存于数据库，be stored in a database 是标准搭配。（易错警示：analyzed 的现代语感强，但空格要的是“存放关系”不是加工动作。） |
| D displayed | 展示的 | ✗ 排除 | display 是屏幕上的呈现动作，不是数据库的存储状态。（典型误解：display 与 computer 的表面联想。） |

代入后的完整句义：我们常听媒体报道：非法黑客能够访问计算机数据库，并篡改其中储存的信息。

### 第 4 步：预判追问

- **为什么必须是过去分词？**：information 与 store 是被动关系（信息被储存），过去分词 stored 作后置定语，相当于 information which is stored there。
- **there 指代什么？**：前半句的 a computer database。“alter information stored there” = 改动储存在数据库里的信息。

### 易错点

- **误选 A（analyzed）**：见 database 就联想数据分析。
- **误选 B（shared）**：把“联网”直接等同于“共享”。
- **误选 D（displayed）**：display 与 computer 的表面联想。

> 记忆锚点：information stored in a database = 库中储存的信息；分词定语问一句“信息与库的基本关系”→ 存放 → stored。
