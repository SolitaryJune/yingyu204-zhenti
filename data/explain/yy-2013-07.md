## 本题讲解：2013 完形第 7 空 · 建一套电子支付设施要花什么——expensive

答案：**A（expensive 昂贵的）**。

### 第 0 步：先立机制——First 的任务：第一条“劝退”理由

First 引出阻碍因素第一条。句型 it is very ___ to set up…：it 是形式主语，真正被评价的是 to set up the computer, card reader, and telecommunications networks（建一整套电子支付基础设施）这件事。段落任务是解释“纸币系统为什么不消失”，所以第一条理由必须能劝退这套建设。评一个“从零铺开的基础设施”，最硬的门槛维度就是钱。

### 第 1 步：定位原文

> First, it is very `__7__` to set up the computer, card reader, and telecommunications networks necessary to make electronic money the `__8__` form of payment.

it is very ___ to do sth：形容词作表语评“做某事”。expensive / imaginative / sensitive / productive 里，只有“代价高”能构成障碍。

### 第 2 步：找证据——评价对象 = 整套设施的建设成本

计算机、读卡器、电信网络——设备、布点、联网，处处是投入；“建不起”正是电子支付推广慢的头号原因，与第 6 空 work against（阻碍）方向一致，也与第 8 空“让电子货币当主角”的目的从句相连。

### 第 3 步：逐项排除

| 选项 | 词义 | 判定 | 理由与典型误解 |
|---|---|---|---|
| A expensive | 昂贵的 | ✓ 当选 | 建整套设施（计算机 + 读卡器 + 电信网络）非常昂贵——支出门槛正是电子化推广慢的头号“劝退”理由，与 work against 方向一致。（易错警示：productive 是孤句里最“通顺”的褒义词，但 First 的任务是找毛病。） |
| B imaginative | 富有想象力的 | ✗ 排除 | 被评价的是“建设施”这件事，谈不上想象力，语义错位。（典型误解：见高科技就联想到想象力。） |
| C sensitive | 敏感的 | ✗ 排除 | sensitive 修饰“问题、数据、话题”尚可，修饰“建系统”不通；且“安全敏感”是第 14 空之后的段落。（典型误解：被后文 security 话题提前带偏。） |
| D productive | 多产的；富有成效的 | ✗ 排除 | 正面评价与“找阻碍”的段落任务相反，方向站错队。（典型误解：孤立看句子通顺就选，忽略 First 的段落使命。） |

代入后的完整句义：首先，建立使电子货币成为主导支付方式所必需的计算机、读卡器和电信网络是非常昂贵的。

### 第 4 步：预判追问

- **it 是形式主语吗？**：是。it is very ___ to set up… 中，真正的主语是不定式短语“建立整套设施”，it 只是占位；空格评的是“建设施”这件事的属性。
- **productive 为什么不行？**：productive 是褒义评价（富有成效的），而 First 的段落任务是“找阻碍”——任何正面评价都站错队。做题时先认领段落任务，再筛词义方向。

### 易错点

- **误选 B（imaginative）**：见高科技就联想到想象力。
- **误选 C（sensitive）**：被后文 security 话题提前带偏。
- **误选 D（productive）**：孤立看句子通顺就选，忽略 First 的段落使命。

> 记忆锚点：First/Second/Third = 段落任务清单；评“建基础设施”先想代价 → expensive；褒义词进不了“找毛病”清单。
