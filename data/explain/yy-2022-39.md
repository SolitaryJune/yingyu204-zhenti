## 本题讲解：2022 阅读 Text 4 第 39 题 · Strohminger 认为干预效果如何

答案：**C（uncertain 不确定的）**。

### 第 0 步：先立机制——人物观点题，读"让步—转折"的深层语气

题干问人物 Nina Strohminger 的看法。观点题的机制：观点藏在表达词的语气里，尤其是 wants（但愿）、but（转折后才是重点）、if real（就算是真的）这三个信号——她希望效果是真的，但不能排除未知混杂变量，就算真也可能被逆转。三个信号层层叠加，指向同一个结论：她**不确定**这个效果。

### 第 1 步：定位原文

> Psychologist Nina Strohminger ... says she wants the effect to be real but cannot rule out some unknown confounding variable. And if real, she notes, it might be reversible by another nudge: "Easy come, easy go."

她希望这个影响是真实的，**但**无法排除某个未知的混杂变量；而且即便是真的，它也可能被另一个轻推**逆转**——"来得快，去得也快"。

### 第 2 步：同义替换对上 C

cannot rule out some unknown confounding variable + might be reversible ↔ uncertain：无法排除他因、随时可逆转，即效果"不确定"。当选。

### 第 3 步：逐项排除

| 选项 | 判定 | 理由与典型误解 |
|---|---|---|
| A permanent | ✗ | 与 might be reversible / Easy come, easy go 方向相反——她说的是易逝。（典型误解：把 held steady（第三段实验数据稳定）迁移成"效果永久"。） |
| B predictable | ✗ | predicted 出现在**第三段**，指向 Schwitzgebel 研究前的预测，且被结果推翻；Strohminger 从未谈"可预测"。（典型误解：见 predicted 就配 predictable，人没有对上。） |
| C uncertain | ✓ | cannot rule out unknown confounding variable + might be reversible 的合理概括。 |
| D unrepeatable | ✗ | reversible（可逆转）≠ unrepeatable（不可重复）；且"即便真也可能逆转"的前提恰恰默认效果可再现。（典型误解：reversible 望文生义成"不可再来一次"。） |

### 第 4 步：预判追问

- **"希望是真的"为什么反而是不确定的证据？**：wants 表达主观愿望而非判断——正因为她**不能**断定，才只能说"希望"。紧随的 but 转折把重心压到"无法排除混杂变量"上：效果可能根本不是干预带来的。
- **if real（如果属实）又在暗示什么？**：条件句本身就表示"尚未坐实"。三个信号（wants、but cannot rule out、if real）都往"存疑"方向推，故 C 是唯一的汇合点。
- **Easy come, easy go 在说什么？**：来得快去得快——强调效果容易消散、不可持续，进一步加固"不确定/不稳固"，同时反向排除 A。

### 易错点

- **误选 A**：把第三段"实验期间数据保持稳定（held steady）"错位到 Strohminger 的态度上，又把"几周平稳"夸大成"永久"。
- **误选 D**：reversible 与 unrepeatable 一词之差——"可逆转"说的是会消退，不是"不可复现"。

> 记忆锚点：观点题读三层语气：wants（愿望≠判断）+ but cannot rule out（转折后是重心）+ if real（条件=未坐实）→ uncertain；reversible ≠ unrepeatable。
