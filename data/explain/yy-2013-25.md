## 本题讲解：2013 阅读第 25 题 · 全文最恰当的标题

答案：**C（Average Is Over 平庸时代结束）**。

### 第 0 步：先立机制——标题题的三条标准

标题题 = 主旨题，判断标准有三条：① **覆盖全文**而非局部（只罩住一段的不是标题）；② 与**作者态度**一致；③ 最好有“文眼”支撑。本文的高频词是 average（平庸的）——第三段有一句宣言式的话统摄全文，这就是文眼。

### 第 1 步：抓文眼

> In the past, workers with average skills, doing an average job, could earn an average lifestyle. But, today, average is officially over.

第三段：过去“平庸”能换来普通生活，But 转折——“**平庸时代正式结束了**”。这句话之后，全文每一部分都在为它服务：平庸不再有回报、要找到独特价值（第三段）→ 岗位加速消失（第四段）→ 好工作要求更高教育（第五段）→ 末段呼吁普及高中后教育，让每个人 above average。average 一词贯穿第一、三、五、六段（average skills / average job / average lifestyle / above average）。

### 第 2 步：逐项排除

| 选项 | 判定 | 理由与典型误解 |
|---|---|---|
| A New Law Takes Effect | ✗ 排除 | 末段只是“建议”通过一部类似 G.I. Bill 的法案（passing some kind of...），并未生效；且法案只覆盖末段对策，撑不起全文。（典型误解：拿末段局部信息当全文标题。） |
| B Technology Goes Cheap | ✗ 排除 | cheap 只在第三段排比里出现（cheap software / robotics / automation...），是局部细节；文章重点不是技术的价格，而是它对劳动者的冲击。（典型误解：原词重现的选项反而要警惕。） |
| C Average Is Over | ✓ 当选 | 文眼句原文照应 + average 贯穿全文 + 与作者“必须超越平庸”的态度一致——三条标准全过。 |
| D Recession Is Bad | ✗ 排除 | 大衰退（Great Recession）只是第二段列出的失业原因之一，非全文主旨。（典型误解：把“原因之一”放大成“主题”。） |

### 第 3 步：预判追问

- **标题题和主旨题的做法一样吗？**：内核一样（概括全文），但标题还要求**有文采的浓缩**——Average Is Over 恰好把文眼句直接提为标题，既覆盖全文（“平庸时代结束”意味着人人要超越平庸、要更多教育）又点明态度。
- **为什么“覆盖全文”这么重要？**：四个干扰项各自都能在原文里找到出处，但 A 只覆盖末段、B 只覆盖第三段的排比、D 只覆盖第二段的一个原因——它们是“段落标题”而非“文章标题”。逐项自问“这个标题罩得住第几段？”就能快速排除。

### 易错点

- **误选 A**：把末段对策（而且是“建议”而非事实）当成全文主题。
- **误选 B**：被原词 cheap 吸引——正确项反而常常不含干扰项那样的“表面原词”，而是抓文眼。

> 记忆锚点：标题 = 文眼 + 高频词 + 态度；But 转折后的宣言（average is officially over）统领全文；逐项问“罩得住几段？”——只罩一段的不是标题。
