## 本题讲解：2022 新题型第 41 题 · 【41】段小标题——恢复锻炼第一课：低起步

答案：**C（Start Low, Go Slow 低起步，慢慢来）**。

### 第 0 步：先立机制——小标题题 = 段旨概括 + 双向验证

小标题匹配的机制是"一段对一题"：先把段落压缩成一句话主旨（通常在观点句/祈使句），再拿候选标题双向验证——正向看标题关键词能否在段内找到同义复现，反向看段内反例是否会推翻标题。只单向匹配（见到某个词就选）必被"局部词干扰项"击中。本题【41】段首句就是祈使句 Don't try to go back...，段旨句提前亮明。

### 第 1 步：定位原文

> Don't try to go back to what you were doing before your break. If you were walking 3 miles a day... reduce activity to half a mile every other day... Increase time, distance, and intensity gradually. "This isn't something you can do overnight"...

段内三步走：①不要试图恢复中断前的运动量；②举例——把运动量减半（3 英里→隔天半英里、10 磅哑铃→5 磅）；③总结——时间、距离、强度都要**循序渐进**（gradually），"这不可能一蹴而就"。

### 第 2 步：正向验证 C

Start Low ↔ reduce activity（把量先降下来）；Go Slow ↔ Increase ... gradually（逐渐加量，别图快）。两半标题在段内都有落点，且覆盖"降起点 + 慢增速"全段，无反例。当选。

### 第 3 步：逐项排除（主要干扰项）

| 选项 | 判定 | 理由与典型误解 |
|---|---|---|
| C Start Low, Go Slow | ✓ | reduce activity ↔ start low；increase gradually ↔ go slow。 |
| A Make It a Habit | ✗ | "坚持/习惯"是【43】段（Consistency is the key）的主旨——张冠李戴。（典型误解：见"每天坚持"字样就近似联想。） |
| G Round Out Your Routine | ✗ | 段中虽出现多种运动项目，但它们是"减量示例"，不是"完善锻炼组合"。（典型误解：被项目列举的丰富感带偏。） |
| D Talk With Your Doctor | ✗ | 全段无医生出场。（典型误解：把"运动安全"泛化成"问医生"。） |

### 第 4 步：预判追问

- **为什么不选 A？段里不也说了"隔天/每周"的安排吗？**：那些频率是"减量方案"的细节，服务于"降低起点"；段的落点是 gradually 与 not overnight——节奏与起点，不是习惯养成。
- **标题题要不要读完全段？**：观点句（首句祈使 + 段末总结）定主旨，例子只做验证。本题首句 Don't try to go back 与末句 gradually 双向锁定，举例部分扫一眼即可。

### 易错点

- **误选 A**：与【43】段主旨串门——两段都讲"该怎么练"，但一段讲"量要低、进度要慢"，一段讲"贵在坚持"。
- **误选 G**：只见列举的运动种类，没见"组合、完善"义。

> 记忆锚点：小标题 = 段旨压缩；reduce + gradually = Start Low, Go Slow；"减半、别过夜"都是"低起步"的证据，习惯论是隔壁段的事。
