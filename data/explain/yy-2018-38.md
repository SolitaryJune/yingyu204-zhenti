## 本题讲解：2018 阅读第 38 题 · 人物观点题——三个分句递进，取最强的那个

答案：**D（an essential factor in accomplishing any work 完成任何工作的必要因素）**。

### 第 0 步：先立机制——引语里的"递进链"，观点取最后最强的一环

题干 According to **Newport**, **idleness** is ____——人物观点题，定位词是人和话题词。Newport 谈 idleness 的那句引语不是一个观点，而是**三个分句的递进链**：①not just a vacation, an indulgence or a vice（先破：闲散不只是假期、放纵或恶习——把"闲散=懒惰"的常识先扔掉）；②as indispensable to the brain as vitamin D is to the body（再立一半：对大脑像维他命 D 对身体一样不可或缺）；③**paradoxically, necessary to getting any work done**（推到最强：矛盾的是，它对完成**任何**工作都必不可少）。观点题取链条的**最后一环**——最强、最新、且带 paradoxically（看似矛盾实则……）信号词的那句。

### 第 1 步：定位原文

> "Idleness is not just a vacation, an indulgence or a vice; it is as indispensable to the brain as vitamin D is to the body… [idleness] is, **paradoxically, necessary to getting any work done**," he argues.

结构：①not just... 先破常识；②as indispensable to the brain as... 类比（大脑需要闲散）；③paradoxically + **necessary to getting any work done**——"闲散是完成任何工作的必要条件"。he argues 坐实这是 Newport 的观点。

### 第 2 步：同义替换——"necessary to getting any work done"就是"essential factor in accomplishing any work"

[D] an **essential** factor in **accomplishing any work** ↔ **necessary** to **getting any work done**：essential ↔ necessary；accomplishing ↔ getting done；any work ↔ any work（原词保留）。方向、程度、对象全对齐。注意 [D] 用的是"绝对肯定表述"（essential factor），很多考生第一眼会怀疑它"太绝对"——但判断标准不是选项听上去是否稳妥，而是**与原文方向和程度是否契合**：原文 necessary to getting any work done 本来就是全称的强表述。

### 第 3 步：逐项排除（干扰项归因）

| 选项 | 判定 | 归因 |
|---|---|---|
| A a desirable mental state for busy people | ✗ | 夸大其词：原文只是"大脑在工作之外需要适时闲散"，被夸成"忙碌人群的**理想心理状态**"（暗示闲散可取、忙碌不可取，用闲散替代忙碌）——程度被放大了一个量级 |
| B a major contributor to physical health | ✗ | 强加关联：类比"闲散之于大脑 ∷ 维他命 D 之于身体"里，"身体"只是**类比项**，闲散对应的直接受益者是大脑；"闲散维持身体健康"把类比的两端错误焊接 |
| C an effective way to save time and energy | ✗ | 关系曲解＋望文生义：⑥段 make the **most of** our focus and energy（**充分利用**精力）被曲解为"**节约**精力"；downtime（休息时间）按构词 down+time 臆断成"省时间"——充分利用 ≠ 节约 |
| D an essential factor in accomplishing any work | ✓ | necessary to getting any work done 的同义改写，递进链最后一环 |

### 预判追问：D 太绝对了，考研阅读里"绝对表述"不都该排除吗？

"绝对表述慎选"是经验，不是铁律——它成立的前提是**原文没有同强度的支撑**。本题恰好相反：原文 necessary to getting **any** work done 本身就是全称强表述，[D] 的 essential factor in accomplishing any work 与它程度完全一致。相反，A、C 这类"听上去留有余地"的选项才是伪稳妥：A 夸大（desirable mental state）、C 曲解（save energy）。观点题的正确姿势是**拿选项与原句逐项比对方向和程度**，而不是给选项的语气打分。

### 易错点

- **误选 A**：把"大脑需要张弛"放大成"闲散是理想状态、忙碌要不得"。
- **误选 B**：类比读反——维他命 D 之于身体是**喻体**，闲散的受益者是大脑，不是身体。
- **误选 C**：make the most of（充分利用）→ save（节约），一字之差方向全变；downtime 望文生义。

> 记忆锚点：观点引语三连 **not just（破）→ as indispensable as（立）→ paradoxically necessary（最强）**，取最后一环；necessary to getting any work done = essential factor；类比项不是受益者；make the most of ≠ save。
