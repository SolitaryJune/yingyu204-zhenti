## 本题讲解：2015 完形第 4 空 · send 的宾语要经得起“冒号复述”

答案：**A（message）**。

### 第 0 步：先立机制——冒号是空格的“同位解释”

`This universal protection sends the __4__: "Please don't approach me."`：冒号后的引语就是空格词的具体内容——“请不要靠近我”。这是主动发给他人的一条人际信息。于是空格同时吃两条约束：(1) 主语 protection 是“物”，物能“发出”的宾语有限；(2) 冒号内容必须能被空格词一句话概括。

### 第 1 步：定位原文

> This universal protection sends the __4__: "Please don't approach me."

上句说人人埋头玩手机形成“普遍的自我防护”，本句说这个姿态“发出”了空格——冒号替空格把话说尽。

### 第 2 步：逐项排除

| 选项 | 词义 | 判定 | 理由与典型误解 |
|---|---|---|---|
| A message | 信息 | ✓ 当选 | send the message 高频搭配，冒号引语正是信息内容。 |
| B code | 代码，密码 | ✗ 排除 | 密码要编码破译，“别靠近我”不是密文。（典型误解：被科技语境带偏。） |
| C notice | 通知 | ✗ 排除 | 通知由人/机构发出并张贴；主语是“物”，发不出通知。（典型误解：只想“提醒别人”，没查主语。） |
| D sign | 迹象，标志 | ✗ 排除 | sign 预示“将发生什么”；“别靠近我”是当下刻意传达的信息。（典型误解：有“示意”义项就填。） |

代入后的完整句义：这种普遍的自我防护传递出一条信息：“请不要靠近我。”

### 第 3 步：预判追问

- **sign 不也有“示意”的意思吗？**：sign 的“示意/迹象”是无意的表露或预示（a sign of trouble）；冒号后是刻意表达的祈使句，是“信息”不是“迹象”。send the message 才是地道搭配。
- **notice 为什么输给 message？**：除了主语是“物”发不出公告，notice 还偏正式文书语域；手机自保姿态传递的是人际态度，语域也对不上。

### 易错点

- **误选 D（sign）**：把“示意”与“信息”混为一谈——最常见错法。
- **误选 C（notice）**：没检查“物作主语”这条搭配约束。
- **误选 B（code）**：被手机、信号的科技氛围带偏。

> 记忆锚点：物作主语 + send + 冒号复述 → message；sign 表迹象，notice 表公告，code 表密码。
