## 本题讲解：2020 完形第 5 空 · Still 定转折，"都想"对"不易"——让步关系选连词

答案：**A（while 尽管；当……时）**。

### 第 0 步：先立机制——两层路标：句首 Still + 句内空格

这句话有两层逻辑要分开看。第一层在句首：Still 是段内转折路标——上一句说"所有年龄段的孩子都受益于耐心育儿"（积极），Still 一转，本句要指出这条路走起来不容易（消极）。第二层在空格：从句说"每个父母都想有耐心"（理想），主句说"这不是件容易的事"（现实）——理想与现实相碰，是让步转折关系："尽管人人都想有耐心，但这并非易事。"空格必须表"尽管"。因果、条件两个方向先排除："人人都想"既不是"难"的原因，也不是"容易"的前提条件。

### 第 1 步：定位原文

> Still, __5__ every parent would like to be patient, this is no easy __6__ .

空格是从句连词，负责"从句 → 主句"的逻辑关系；选它之前先把两句话各说什么摆清楚。

### 第 2 步：梳理句内逻辑——从句与主句语义方向相反

- **从句**：every parent would like to be patient（人人向往——正面）；
- **主句**：this is no easy ____（并不容易——负面）；
- **关系判定**：两句语义方向相反且同时成立 → 让步（尽管）；Still 在句首已经预演了同样的转向。

### 第 3 步：逐项排除

| 选项 | 词义 | 判定 | 理由与典型误解 |
|---|---|---|---|
| A while | 尽管；当……时 | ✓ 当选 | 取"尽管"义：从句让步、主句转折，"虽然人人都想有耐心，但这并非易事"，与 Still 的转向一致。 |
| B because | 因为 | ✗ 排除 | 表因果："都想有耐心"并不会"导致"耐心难达成——"向往的事往往不易"是常理错觉，不是句子内部的因果。（典型误解：套用"人人向往的事都不容易"的因果直觉。） |
| C unless | 除非 | ✗ 排除 | 表条件：读成"除非人人想有耐心，否则这不容易"——"人人都想"并不是"容易"的前提条件，逻辑不成立。 |
| D once | 一旦；曾经 | ✗ 排除 | 表条件/时间："一旦人人想有耐心，这就不容易"同样讲不通。 |

代入后的完整句义：不过，尽管每位父母都想做到有耐心，这却不是一件容易的事。

### 第 4 步：预判追问

- **while 不是"当……时"吗？**：while 是兼类词：既可表时间"当……时"，也可表让步"尽管"。此处两句是"理想 vs 现实"的让步转折，不是时间关系，取"尽管"义。

### 易错点

- **误选 B（because）**：把"向往 vs 现实"的常理反差误当句子内部的因果关系。

> 记忆锚点：Still = 段内转折路标；从句正面 vs 主句负面 → 让步 while（尽管）；because/unless/once 各表因果条件，先定关系再选词。
