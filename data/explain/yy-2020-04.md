## 本题讲解：2020 完形第 4 空 · easier 咬住首段 defining——不定式主动表被动的陷阱

答案：**C（describe 描述；形容）**。

### 第 0 步：先立机制——先找对照点，再核语法关系

这个空有三层线索。第一层是词汇复现：首段反复出现 defining what it means to be a good parent——"界定/描述好父母"难（tricky）；本句 another sort of parent that's a bit easier to ____ 是与它对照的：另一种父母，"____"起来更容易。空格词必须与 defining 同义复现。第二层是语法结构：be + 形容词 + to do 中，不定式用主动形式表被动意义——a parent (who is) easier to describe，即"容易被描述的父母"；parent 是空格动词的逻辑宾语，不是主语。第三层是排除法：剩下三个动词都是"父母对孩子"方向的惯常动作，正好掉进把 parent 当主语的陷阱。

### 第 1 步：定位原文

> __3__ , there's another sort of parent that's a bit easier to __4__ : a patient parent.

空格在 easier to ____ 结构中，说明 parent 的性质；对照点在首段：defining what it means to be a good parent（界定好父母）很难。

### 第 2 步：找证据——defining 的同义复现

- **首段**：defining what it means to be a good parent is very tricky（"界定好父母"难）；
- **本句**：another sort of parent that's a bit easier to ____（另一种父母更易____）；
- **同义复现**：easier 的对照对象就是 defining/describe——describe（描述、形容）与 defining 同族；
- **语法核验**：be + adj + to do 主动表被动：easier to describe = 容易"被描述"。

### 第 3 步：逐项排除

| 选项 | 词义 | 判定 | 理由与典型误解 |
|---|---|---|---|
| A amuse | 逗乐；提供消遣 | ✗ 排除 | "容易被逗乐的父母"与"界定标准"无关——干扰来自"耐心父母让孩子开心"的惯性联想，且把 parent 误当主语读成"父母去逗乐（孩子）"。（典型误解：忽略 easier 与 tricky 的对照，掉进"父母逗孩子开心"的惯常思维。） |
| B assist | 帮助，协助 | ✗ 排除 | "容易被帮助的父母"同样接不上"界定标准"的语境，干扰方向同 A。 |
| C describe | 描述；形容 | ✓ 当选 | 与首段 defining 同义复现，easier to describe = "更好描述"，对照严丝合缝；主动形式表被动意义，语法成立。 |
| D train | 训练，培训 | ✗ 排除 | "容易被训练的父母"文意不通——文章不是在给父母分培训班；干扰同样来自"父母要训练孩子"的惯性联想。（典型误解：把不定式读成主动"父母去训练"，忽略主宾关系。） |

代入后的完整句义：还有一种父母要更容易"描述"一些：有耐心的父母。

### 第 4 步：预判追问

- **train 不也是常见动词吗，"容易训练的父母"哪里不通？**：两处不通：一是 easier 的对照对象是首段"界定难"——"容易训练"接不上这个对照；二是 be+adj+to do 里 parent 是动词的逻辑宾语，读成"父母去训练（孩子）"更是方向反了。

### 易错点

- **误选 D（train）**：忽略 easier ↔ tricky 的呼应，把"父母训练孩子"的惯常思维代入空格。

> 记忆锚点：easier to ____ ↔ 首段 tricky/defining → describe；be+adj+to do 主动表被动，主语是动词的宾语。
