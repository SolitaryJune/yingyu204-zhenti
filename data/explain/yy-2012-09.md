## 本题讲解：2012 完形第 9 空 · “never __9__ it to the top”的虚指 it

答案：**C（made （make it）成功）**。

### 第 0 步：先立机制——本空的解题结构

a guy who never __9__ it to the top：空格动词后面跟着 it 和 to the top。这个 it 不指任何具体事物，是习惯搭配里的“虚指 it”——能这样带 it 的就是 make it（成功、办成）。所以本题先认搭配：make it to the top = 出人头地、登上顶层；其余三个动词与“动词 + it + to the top”的框架全部不合。

### 第 1 步：定位原文

> And Joe? A common name for a guy who never __9__ it to the top. Joe Blow, Joe Palooka, Joe Magrac...a working class name.

空格是从句谓语，宾语位置是 it，后接 to the top。it 无先行词指代——这正是“虚指 it”（结构固定搭配）的信号。

### 第 2 步：找证据——working class name 与下句把方向钉死为“从未登顶”

> Joe Blow, Joe Palooka, Joe Magrac...a working class name. The United States has never had a president or vice-president or secretary of state Joe.

一连串工人阶层的名字 + 下句“美国从未有过名叫 Joe 的总统”：Joe 这个名字的主人们从未爬上顶层。空格语义 = 从未成功登顶。

### 第 3 步：逐项排除

| 选项 | 词义 | 判定 | 理由与典型误解 |
|---|---|---|---|
| A pushed | 推；逼迫 | ✗ 排除 | 口语 push it 指“过分要求、得寸进尺”（Don’t push it），与“登上顶层”毫无关系。（典型误解：把“推到顶端”的中文字面义硬接上去。） |
| B got | 得到；明白 | ✗ 排除 | get to the top（到达顶层）要去掉 it；got it to the top 变成“把它弄上顶”，it 无指代，语义崩塌。（典型误解：把 get to the top 与 make it to the top 两个结构杂糅。） |
| C made | （make it）成功 | ✓ 当选 | make it 为固定搭配，义为“获得成功、办成”：make it to the top = 成功登上顶层；never made it = 从未出人头地。如 He never really made it as an actor. |
| D managed | 勉力完成 | ✗ 排除 | manage 表示“设法办成”要接不定式：manage to do sth；manage it to the top 不是英语结构。（典型误解：中文“做到”都对应 make/manage，没查各自的句型框架。） |

代入后的完整句义：Joe？是从未成功出人头地的普通人常用的名字——Joe Blow、Joe Palooka、Joe Magrac，一水儿的工人阶层名字。

### 第 4 步：预判追问

- **make it 的 it 到底指什么？**：什么都不指——它是固定搭配的组成部分（虚指 it），类似 get it（明白）里的 it。整个 make it 才等于“成功”，拆开逐词翻译就散架了。
- **为什么 D 的中文释义“完成”不对？**：manage 的“完成”必须落在 manage to do sth 句型上（He managed to finish it）；本空后面是 it + to the top，句型对不上，中文再近也进不来。

### 易错点

- **误选 B（got）**：两个近义结构杂糅：get to the top 与 make it to the top 各取一半。
- **误选 D（managed）**：只对中文释义，没查 manage + to do 的句型要求。
- **误选 A（pushed）**：push it 的口语义“得寸进尺”与登顶无关。

> 记忆锚点：make it (to the top) = 出人头地；虚指 it 只认 make it；manage 必须接 to do；get to the top 不带 it。
