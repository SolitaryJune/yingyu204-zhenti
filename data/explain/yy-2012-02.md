## 本题讲解：2012 完形第 2 空 · “成长为英雄”的反差里该填哪种“人”

答案：**B（common 普通的）**。

### 第 0 步：先立机制——本空的解题结构

the __2__ man grown into hero 是一个反差结构：空格词必须与 hero（英雄）形成落差，“成长为”三个字才立得住。紧接着的两个同位语 the poor farm kid、the guy who bore all the burdens 都在给这个空格词举例。所以解题顺序是：先锁定“反差”，再找全文对这个反差的同义复现。

### 第 1 步：定位原文

> To the men and women who served in World War Ⅱ..., the G.I. was the __2__ man grown into hero, the poor farm kid torn away from his home.

空格是修饰 man 的形容词，与 grown into hero 连用：某一种“……的人”长成了英雄。反差成立的前提是空格词落在“平凡”一端。

### 第 2 步：找证据——同一句和下一段把这个词说了三遍

> This was not a volunteer soldier, not someone well paid, but an average guy. / A common name for a guy who never made it to the top... a working class name.

段末 an average guy（普通人）和第二段 a common name、a working class name 是本空的同义复现链：平凡大众 = common。答案应当落在 common 一族。

### 第 3 步：逐项排除

| 选项 | 词义 | 判定 | 理由与典型误解 |
|---|---|---|---|
| A actual | 真实的；实际的 | ✗ 排除 | actual 强调“事实上、名副其实”，本身没有平凡义；“真实的人成长为英雄”缺张力，也和下文 average guy 对不上。（典型误解：把 actual man 读成“（不是玩具而是）真人”，错把开头的 mindless war toy 当成本空的对照物。） |
| B common | 普通的 | ✓ 当选 | common man 即“平民、普通人”，与段末 an average guy、第二段 a common name 双重同义复现，“普通人成长为英雄”正是全文主旨。 |
| C special | 特别的 | ✗ 排除 | special 与 hero 同向：本来特别的人当英雄无所谓“成长”；它与 the poor farm kid、an average guy 直接冲突。（典型误解：被“英雄”带偏，忘了空格词必须在平凡一端。） |
| D normal | 正常的；标准的 | ✗ 排除 | normal 的核心是“符合常态、身心正常”，不含“大众、平民”义，与下文 working class（工人阶层）对不上。（典型误解：中文释义都带“普通/正常”，没区分 common（平凡大众）与 normal（标准无异常）。） |

代入后的完整句义：G.I. 是成长为英雄的普通人，是被硬生生拽离家园的贫苦农家孩子。

### 第 4 步：预判追问

- **common 与 normal 不都是“普通”吗？**：common 的核心是“共有、常见”——大街小巷人人有份；normal 的核心是“符合标准、不反常”。平民英雄要的是“大众中的一员”，所以选 common；normal man 反而暗含“其他人不正常”，语义落空。
- **actual 的“真人”义为什么不行？**：“不是玩具是真人”是文章首句要纠正的大众印象，不是本句的句内结构。本句内部只有“……man grown into hero”一个对照，actual 与“成长”无关。

### 易错点

- **误选 D（normal）**：近义词辨析粗放：没分清“平凡大众”与“正常标准”。
- **误选 C（special）**：忽略 grown into hero 的反差结构，选了与 hero 同向的词。
- **误选 A（actual）**：用首句“war toy 对照”的联想替代句内证据。

> 记忆锚点：平凡→英雄的张力 = common man grown into hero；average guy / common name / common man 三重复现；normal 只管“正常”不管“平凡”。
